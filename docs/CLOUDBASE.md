# Edu_chat 云端部署指南（腾讯云 CloudBase 云托管）

目标：把 `server/index.mjs`（Node 网关）部署到云端，手机通过 HTTPS 访问，电脑关机后仍可用。**不需要改源码，也不需要重新打包 APK。**

本项目的后端是长连接 Node 服务（流式回答最长 180 秒），因此用「云托管（Cloud Run）」跑容器，**不是**「静态托管」或「云函数」。

## 一、先准备好两样东西

### 1. DeepSeek 密钥（你自己去拿）

- 打开 https://platform.deepseek.com ，登录（手机号/邮箱均可）。
- 左侧「API Keys」→「创建 API Key」，复制以 `sk-` 开头的一串字符。
- **这串字符只允许填在云端的私密环境变量里**，不要发到聊天、不要写进代码或 Git。

### 2. 应用访问令牌 APP_TOKEN（本机生成）

在本机 PowerShell 里运行（已装 Node）：

```powershell
node -e "console.log(require('node:crypto').randomBytes(32).toString('hex'))"
```

会输出 64 位随机串，这就是 `APP_TOKEN`。先复制保存到手机备忘录或密码本，一会儿云端和手机各填一次。它不是 DeepSeek 密钥，但也要保密。

## 二、开通云开发环境（首次，约 2 分钟）

1. 浏览器打开 https://console.cloud.tencent.com/tcb （腾讯云「云开发 CloudBase」控制台）。
2. 用微信扫码或手机号登录腾讯云。首次会提示「开通云开发」，同意协议并开通。
3. 新建一个环境：地域选离你近的（如「上海」），计费先选**免费版/按量付费**即可，环境名随意（如 `edu-chat`）。

## 三、云托管部署（用现有 Dockerfile）

1. 在刚建的环境左侧菜单点「**云托管**」。
2. 点「**新建服务**」，服务名填 `edu-chat`。
3. 部署方式选「**本地代码/上传代码**」或「**代码仓库**」：
   - 本地上传：把项目根目录打包成 zip 上传（含 `Dockerfile`）。
   - 代码仓库：可先推送到 GitHub/Gitee 再关联，选 Dockerfile 构建。
4. 「监听端口」：填 **80**（若界面显示平台会自动注入 PORT 就不用改；程序会自动读取 PORT 环境变量）。
5. 实例规格先选最小档 **0.25 核 0.5G**。

## 四、环境变量（最关键，密钥只填这里）

在服务配置的「环境变量」里逐条添加：

| 变量名 | 值 |
| --- | --- |
| `HOST` | `0.0.0.0` |
| `PUBLIC_ORIGIN` | `https://你实际拿到的域名`（见第五步，先放这里，拿到域名后回来改） |
| `DEEPSEEK_API_KEY` | 你刚复制的 `sk-...` 密钥 |
| `APP_TOKEN` | 你刚生成的那串 64 位随机串 |
| `DEEPSEEK_API_ORIGIN` | `https://api.deepseek.com`（默认，可不填） |

可选：`RATE_LIMIT_PER_MINUTE`（默认 60）、`MAX_BODY_BYTES`（默认 33554432）。

要点：`PUBLIC_ORIGIN` 必须和最终外部访问的 HTTPS 域名**完全一致**，且是 `https://` 开头、末尾**不要**带 `/api`。`APP_TOKEN` 至少 16 字符。

## 五、开启公网访问，拿到 HTTPS 域名

1. 在云托管服务的「公网访问 / 访问路径」里开启公网访问。
2. 系统会给你一个默认域名，形如 `https://xxxx.tcloudbase.com`（或 `...app.tcloudbase.com`）。
3. 把这一步的域名填回第四步的 `PUBLIC_ORIGIN`（只填域名部分，如 `https://xxxx.tcloudbase.com`），保存后重新部署/重启服务。
4. 记下这个域名，一会儿手机要填。

> 想用自己买的域名：在「自定义域名」里绑定并解析，再配 HTTPS 证书即可；个人先用默认域名最省事。

## 六、避免休眠 / 保证流式

- **避免冷启动（休眠）**：在服务的「伸缩配置」里把「最小副本数」设为 **1**（常驻，约 ¥24~35/月）。设为 0 则空闲时缩容到 0，下次第一条消息要等几秒冷启动，但不影响关机后可用。
- **流式不卡顿**：把「请求超时时间」调到 **300 秒**（大于网关的 180 秒）；确认网关没有对 SSE 做缓冲（腾讯云托管默认支持，若流式变成一次性输出，回来检查此超时项）。

## 七、手机连接（App 内操作）

1. 打开 App，点首页的「设置服务器，开始聊天」。
2. 「服务器地址」填第五步的 `https://xxxx.tcloudbase.com`。
3. 「访问令牌」填你的 `APP_TOKEN`。
4. 点「保存并连接」，出现「已连接服务端」即成功。
5. 依次验证：普通聊天 → 流式输出 → 停止生成 → 深度思考 → 搜索 → 文件。

## 八、费用与关闭

- 免费版每月有约 3000 资源点额度，个人轻度聊天够用；超了免费版会停，可升级个人版（¥19.9/月）或按量。
- 常驻实例按秒计费，约 0.25核0.5G ≈ 每小时几毛钱；不常驻（最小实例 0）更省。
- 不想要了：在云托管服务里「删除服务」，并可在环境里删除环境，避免持续扣费。
