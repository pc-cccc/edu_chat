# V0.1 验证记录

品牌更新：知学 Chat 已更名为 Edu_chat，首页与浏览器标签图标改为简洁钥匙。下文为 V0.1 原始功能验证记录；本次品牌修改另行通过类型检查、生产构建与页面检查。

日期：2026-11-17。环境：Windows、Node.js v26.13.0、pnpm 11.25.0、本机浏览器。上游源码提交见 NOTICE.md。

## 已执行并通过

- 使用上游锁文件安装依赖；未更换技术栈、未添加后端依赖。
- `pnpm type`：TypeScript 类型检查通过。
- `pnpm build`：生产服务端版构建通过；附带 dist 产物。
- `pnpm build:direct`：静态直连版构建通过，随后重新构建服务端版作为交付版本。
- `pnpm test`：11 个 Node 集成测试全部通过。测试使用本机服务与模拟上游，不产生 API 费用。
- `pnpm demo` 实际启动，浏览器显示首页及演示标识。
- 浏览器点击学习入口，确认文字填入输入框；发送后观察到流式响应与停止按钮。
- 开启深度思考后观察到“正在思考”与完成后的思考面板。
- 浏览器看到 KaTeX 公式、Markdown 表格、Python 代码高亮。
- 重新生成后停止，确认停止生效、版本切换器出现且保留已有内容。
- 刷新后从侧边栏重新打开会话，确认提问、回答和思考内容持久化。
- 390 × 844 手机视口检查欢迎页、输入框、快捷入口、侧边栏与历史会话。
- `pnpm start` 实际提供生产页面；浏览器成功加载脚本、样式、配置状态，缺少密钥时显示准确的配置提示。
- 生产页面控制台检查没有捕获到 JavaScript error；浏览器检查仅覆盖本次已操作流程。
- `git diff --check` 通过；LICENSE 与上游保持一致。

11 项集成测试覆盖：配置缺失、服务端密钥注入及客户端凭据隔离、SSE 字节流转发、multipart 附件原样转发、供应商错误脱敏、对外绑定配置约束、附件失效错误兼容、静态/API 鉴权、Host/跨站/路径白名单、大小及频率限制、演示流与不支持能力提示、客户端断开后取消上游（部分项目在同一测试中断言）。
