# Edu_chat

以 Android App 为核心的开源 DeepSeek 聊天客户端，支持网页版。当前版本为 **v0.4.7**，使用你自己的 DeepSeek API Key，无需部署服务器或注册 Edu_chat 账号。

- **[中文使用指南](README.md)**：下载、安装、获取 Key、首次聊天、备份与常见问题。
- **[下载 Android App](https://github.com/pc-cccc/edu_chat/releases/latest)**：在 Assets 中选择 `.apk` 文件，不需要下载源码。
- **[打开网页版](https://edu-chat-9yt.pages.dev)**：在自己的浏览器中填写 Key 即可使用。
- [English](README.en.md)

Edu_chat 开源免费，模型调用费用由你的 DeepSeek 开放平台账户承担。本项目非 DeepSeek 官方产品。
